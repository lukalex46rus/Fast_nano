**Границы:** единственный источник истины по истории решений (ADR). Формат: контекст →
решение → следствие. Правила-инварианты → INVARIANTS.md; контракты → CONTRACTS.md;
бюджеты → RESOURCES.md. Здесь — ПОЧЕМУ принято решение, а не как оно работает.

## Отклонённые альтернативы (⛔)

| Альтернатива | Почему отклонена |
|---|---|
| Adafruit_*, U8g2 | накладные расходы flash/SRAM, вне бюджета |
| Servo.h / SoftwareSerial / Wire / SPI (сторонние) | конфликт векторов/ресурсов, нет контроля владения |
| Таблицы CRC в RAM | ~4× flash против побитового |
| Таблицы указателей портов | 18 Б SRAM + косвенный доступ |
| pushOverwrite в RingBuffer | ломает SPSC (двигает _tail потребителя) |
| Асинхронный Timer2 | TOSC занят кварцем Nano |
| Реестры декодеров/каналов в модулях | SRAM + обход в ISR; заменены ctx=this |

## Требуют пересмотра (⚠️)
- D32: номер бита WGM02/22 в комментарии Traits0 ошибочен (бит 3, не 4) → P0-3.
- D69: tmr::acquire описан, но не реализован → P0-4.
