# Fast_nano — контракты и реестр решений

Живой документ. Меняется при каждом изменении API ядра или владения ресурсом.
Приоритет над ROADMAP.md: если план расходится с этим файлом, прав этот файл.

Редакция: после закрытия слоёв pin / timer / PWM / bus / store / peripheral.
Следующий слой: logic.

---

## 1. Цель и границы

- МК: ATmega328P / ATmega328. Остальные AVR, ESP, любые не-AVR — вне проекта.
- Тулчейн: Arduino IDE 2.3.10, avr-gcc 7.3.0, `-std=gnu++11`, `-Os -flto`,
  `-fno-exceptions -fno-threadsafe-statics`.
- Бюджет: SRAM 2048, flash 32768, EEPROM 1024.
- Раскладка: `library.properties` + `src/` (формат 1.5). Иначе `.cpp` из
  подпапок не компилируются. `dot_a_linkage=false` — иначе теряется `.init3`.
  **Подтверждено.**

Внешние зависимости: только avr-libc и стандарт C++11.
`Arduino.h` допустим в прикладных слоях; ядро по возможности чистое.
Отвергнуто: Adafruit_*, U8g2, Servo.h, SoftwareSerial, Wire, SPI (сторонние).

Исключение по avr-libc: тайминг-критичные последовательности (EEPROM
EEMPE→EEPE, `_delay_loop_*`) делегируются avr-libc, а не пишутся вручную.
Ручной C-код на границе 4-тактового окна ломается при смене -O или LTO.

## 2. Жёсткие правила (нарушение = баг, не стиль)

| № | Правило | Почему |
|---|---|---|
| R1  | Таблицы только в PROGMEM, централизованы в `Tables.cpp` | `const` без PROGMEM на AVR = `.data`, то есть SRAM |
| R2  | Строки диагностики только через `PSTR`/`FN_PSTR` | `__FILE__` — полный путь, десятки байт SRAM на ассерт |
| R3  | Никакой 64-битной арифметики и float в горячих путях | `__udivdi3` ≈ 400 Б, soft-float ≈ 600 Б flash |
| R4  | Внутренние циклы по указателям, не по 16-битным индексам | индексная арифметика дороже на AVR |
| R5  | Один вектор = один владелец, заявка через `FN_CLAIM_VECTOR` | два ISR = `multiple definition of __vector_N` |
| R6  | Все ISR живут в `.cpp`, никогда в заголовке | umbrella из двух TU даст дубликаты |
| R7  | Многобайтовые обращения к разделяемым данным — под `AtomicBlock` | старший байт идёт через TEMP, ISR между байтами портит |
| R8  | Порядок настройки вывода: сначала PORT, потом DDR | иначе glitch — например HIGH после INPUT_PULLUP→OUTPUT |
| R9  | Гейт внутри модуля (`#if F_USE_X`), флаги меняются централизованно | per-TU переопределение = нарушение ODR, компилятор молчит |
| R10 | Имена не совпадают с макросами Arduino | `bit`, `bitRead`, `min`, `max`, `swap`, `byte`, `word`… препроцессор не знает namespace |
| R11 | Нет идентификаторов `_Заглавная` | зарезервировано стандартом во всех областях |
| R12 | Проверки границ и nullptr обязательны | `FN_BITS_CHECKS`, `Result::BadArg` |
| R13 | Никаких бесконечных ожиданий железа. Только `fn::expired()`/`expiredUs()` | счётчик итераций зависит от -O и версии GCC; при неинициализированной периферии флаг не выставится никогда |
| R14 | Подбор делителя — максимальная частота, НЕ превышающая запрос | округление вверх разгоняло SPI в 4.17 раза выше заданного |
| R15 | Коды режимов/делителей берутся из даташита, не из порядкового enum | `set_sleep_mode(uint8_t(enum))` давал ADC вместо PowerDown; CS2x ≠ CS0x |
| R16 | Open-drain: «высокий» = input без подтяжки, не `PORT |= mask` | подтяжка 30–50 кОм даёт фронт в мкс; на 400 кГц связи нет |
| R17 | RAII-объект не выполняет глобальный побочный эффект в деструкторе | `TransferGuard`/`I2cScope` гасили шину из локального объекта |
| R18 | Проверка диапазона приёмника перед сужающей записью | `uint8_t(256)` = 0: 100% скважности превращалось в 0% |
| R19 | Регистровый драйвер не заявляет владение устройством; заявляет потребитель |
      | Timer1::takeover с FN_CLAIM_TIMER запрещал всех потребителей сразу |
| R19 | Регистровый драйвер не заявляет владение; заявляет потребитель |

## 3. Реестр ресурсов

### Векторы

| Вектор | Владелец по умолчанию | Можно отдать? |
|---|---|---|
| INT0, INT1 | ARDUINO | **нет** — ISR в `WInterrupts.c`, работаем через `attachInterrupt` |
| TIMER0_OVF | ARDUINO | **нет** — `millis/micros/delay` |
| PCINT0/1/2 | IRQ | да, в ядре Arduino не определены |
| TIMER0_COMPA/B | NONE | да |
| TIMER1_CAPT/OVF/COMPA/B | NONE | да |
| TIMER2_OVF/COMPA/B | NONE | да |
| USART_RX | UART (при использовании Uart) | да |
| USART_UDRE | NONE | да, для своей TX-машины |
| SPI_STC | SPI (при использовании Spi) | да |
| TWI | I2C (при использовании I2c) | да |
| ADC | ADC | да |
| ANALOG_COMP | ADC (та же аналоговая подсистема) | да |
| WDT | USER (Watchdog) | да |

Заявки ставятся в `.cpp` модуля. Для шаблонных движков (PWM) — в прикладном
коде на уровне файла: `static_assert` в теле шаблона сработал бы при
инстанцировании любого метода любого таймера.

### Таймеры целиком

| Таймер | Владелец | Претенденты | Ограничения |
|---|---|---|---|
| Timer0 | ARDUINO | Tick (клиент), Pwm0, Timer0 | смена TOP/CS ломает `millis()`; PWM только через COM/OCR |
| Timer1 | NONE | Pulse (capture), Pwm1, Servo, Stepper | ровно один потребитель |
| Timer2 | NONE | Pwm2, Timer2 | делители свои: 1/8/32/64/128/256/1024 |

### Шина как ресурс

| Ресурс | Владелец | Освобождение |
|---|---|---|
| USART0 + D0/D1 | Uart | `Uart::end()` |
| SPI + D10..D13 | Spi | `Spi::end()` (прежнее состояние пинов НЕ восстанавливается) |
| TWI + A4/A5 | I2c | `I2c::end()` |
| ADC | Adc | `Adc::end()`; компаратору в режиме Mux нужен ADEN=0 |
| EEPROM | Eeprom | не захватывается, но запись 3.4 мс/байт блокирует |

Порядок освобождения перед сном: сначала `Xxx::end()`, затем
`Power::disable(...)`. Отключение PRR при активной периферии оставляет
её в неопределённом состоянии.

### Выводы с двойным назначением

| Вывод | Функции | Конфликт |
|---|---|---|
| D0/D1 (PD0/PD1) | RX/TX USART0 | занят при Uart |
| D2 (PD2) | INT0 | — |
| D3 (PD3) | INT1 / OC2B | PWM на D3 убивает INT1 |
| D5 (PD5) | OC0B / T1 | внешнее тактирование Timer1 vs PWM |
| D6 (PD6) | OC0A / AIN0 | CTC по OCR0A убивает PWM и `millis()`; компаратор |
| D7 (PD7) | AIN1 | компаратор |
| D8 (PB0) | ICP1 | захват Pulse; ACIC компаратора тоже сюда |
| D9/D10 | OC1A/OC1B | PWM Timer1 vs Servo |
| D10 (PB2) | SS SPI | обязан быть выходом в режиме мастера |
| D11 (PB3) | OC2A / MOSI | PWM vs SPI |
| D12 (PB4) | MISO | SPI |
| D13 (PB5) | SCK / LED | SPI vs светодиод платы |
| A4/A5 (PC4/PC5) | SDA/SCL | TWI vs GPIO/ADC |
| A6/A7 | ADC6/ADC7 | только ADC, цифрового порта нет |
| PB6/PB7 | кварц / TOSC | асинхронный Timer2 невозможен на Nano |
| PC6 | RESET | только при RSTDISBL, после чего ISP недоступен |
| PC7 | — | физически отсутствует |

## 4. Контракты API (что нельзя ломать без записи здесь)

### Типы
- `fn::Pin` — 1 байт, `(port<<3)|bit`, `NoPin` = 0xFF. `valid()` проверяет
  диапазоны и отсутствие PC7; физические ограничения — на `pin/Board.h`.
- `fn::Result` — enum class uint8_t: Ok, Fail, BadArg, OutOfRange, NoBuffer,
  Busy, Timeout, NotReady, Unsupported, CrcError, **AddrNack, DataNack**.
  `bool` — только для бинарного исхода. Свой enum с Ok/Timeout/Busy запрещён.
- Трейты в `Types.h`: `Select`, `Id`, `UnsignedOf`, `IsBitType`, `WidthOf`, `UBits`.
  Дублировать в других модулях запрещено.
- `resultName()` — объявление в `Types.h`, определение в `Tables.cpp`.

### Регистры
- Адрес = `_SFR_MEM_ADDR(PINB) + 3*port + reg`. Таблиц указателей нет.
- `toggle()` пишет маску в PINx (аппаратная инверсия, атомарно).
- Раскладка SFR проверяется рантаймово (`layoutOk()`), не `static_assert`:
  `&PORTB` не является constant expression.

### Битовый слой
- Инвариант: биты за пределами N всегда ноль. `normalize()` публичный.
- `operator~` константный, возвращает значение; `invert()` — in-place.
- `BitSetWide` без операторов по значению: буфер разделяемый.
- CRTP-ядро внутри `BitPack.h`, `BitPack<N>` и `BitPackWide` — один API.

### Прерывания
- Коллбэк: `void(*)(void* ctx, Pin changed)`. Есть перегрузка для `void(*)()`.
- Слот 5 байт, пул `FN_IRQ_SLOTS` (8) = 40 байт + 6 на INT.
- ISR передаёт `prev ^ now`, а не уровень.
- Прикладные модули не пишут своих ISR и не зовут `attachInterrupt` напрямую.
- Исключение: шины (USART/SPI/TWI/ADC/AC/WDT) владеют уникальными векторами
  и определяют ISR сами — диспетчер им не нужен, достаточно заявки.
- Прикладной модуль с N экземплярами регистрирует каждый экземпляр отдельно
  с ctx = this. Реестры внутри модулей не заводятся.
- Инициализация объекта завершается ДО регистрации в диспетчере; при отказе
  повторной регистрации первая снимается.

### Время
- Timer0 принадлежит ядру. Сравнения времени только через `expired()`/
  `elapsed()` — прямое `millis() > deadline` ломается на переполнении.
- Разрешение `micros()` — 4 мкс. Для точности до такта — InputCapture.
- `Timeout`/`Stopwatch` — неблокирующие, sizeof 8 байт каждый.
- `delayUsPrecise` запрещает прерывания на всё время: при us=1000 это 1 мс
  без обслуживания ISR. Накладные расходы цикла компенсированы.
- Блокирующие измерители (`PulseInput`, `sonarMeasure`) декларируют худший случай
  блокировки в шапке. Для кооперативного планировщика бюджет ставится по
  худшему ожидаемому сигналу, а не «с запасом».

### Диагностика
- `Crash` — общий узел: `.noinit` (12 байт), `.init3`-захват MCUSR, halt/forceReset.
- `Assert` и `Reset` — тонкие обёртки, свою работу с WDT не заводят.
- Политика по умолчанию Halt (cli + wdt_disable), Reset — осознанно.
- Объявление `fnCrashStartup` обязано предшествовать asm-стабу `.init3`.
- `stackPaint()` не красит верхние ~64 байта (свой кадр): `stackUsed()`
  занижает результат, абсолютное значение — нижняя граница.

### Шины (новый раздел)
Контракт `core/BusContract.h`. Каждая шина предоставляет:
- `using Config = ...`
- `static Result begin(const Config&); static void end(); static bool ready();`
- `static Result write(const uint8_t*, uint16_t);`
- `static Result read(uint8_t*, uint16_t, uint32_t timeoutMs);`
- `static Result transfer(const uint8_t* tx, uint8_t* rx, uint16_t);`
- `static uint16_t available(); static Result flush(uint32_t); static bool busy();`

- Хелперы принимают **саму шину** параметром шаблона, не отдельный тег:
  `fn::bus::writeP<fn::Uart>(FN_PSTR("hi"))`.
- Общие: `waitUntil(pred, ms)`, `waitUntilUs`, `writeByte/writeP/writeStr/writeLine`,
  `transferFill<Bus>(rx, len, fill)`.
- `timeoutMs == 0` — одна проверка без ожидания. Бесконечного ожидания нет.
- Без буфера (SPI/I2c) `available()` = 0, `flush()` = Ok сразу.
- Без приёма (SoftUartTx) `read()` = Unsupported.

Буфер `bus/Buffer.h`:
- Монотонные индексы (не свёрнутые), разность различает пусто/полно.
- **N — степень двойки** (`static_assert`): `% N` при нечётном N = вызов
  `__udivqi3` на каждый байт.
- Index 8-битный при N ≤ 128, 16-битный при N ≥ 256.
- SPSC: push/write — только производитель, pop/read — только потребитель.
  При 8-битных индексах блокировка не нужна.
- `pushOverwrite` удалён: двигал `_tail`, которым владеет потребитель.
- `dropped()` — счётчик отказов push, диагностика потери байтов.

UART:
- Приём **всегда** через ISR в кольцевой буфер: аппаратный буфер 2 байта.
- Флаги FE/DOR/UPE читаются до UDR0; битые кадры отбрасываются и считаются.
- UBRR с округлением в обоих режимах; ошибка > 3‰ порога → OutOfRange,
  настройка применяется.
- SoftUartTx: тайминг в тактах, не в мкс; секция на байт (1.04 мс при 9600).

I2C:
- Частота через TWBR **и прескалер TWPS**: диапазон 490 Гц…1 МГц при 16 МГц.
- Таймаут на каждую фазу, не на транзакцию.
- `recover()`: TWEN=0, open-drain, 9 тактов, проверка освобождения линий.
- SoftI2c: настоящий open-drain, clock stretching с таймаутом.
- `I2cTransaction` делает STOP только если транзакция открыта этим объектом.

SPI:
- Делители 2/4/8/16/32/64/128; минимум F_CPU/128 = 125 кГц при 16 МГц.
  Запрос ниже → OutOfRange, настройка не меняется. Медленнее — SoftSpi.
- Основная операция `transfer` (full-duplex); `read` = transfer с fill 0xFF.
- SS (D10) обязан быть выходом: низкий уровень сбрасывает MSTR аппаратно.
- SoftSpi: все 4 режима CPOL/CPHA + LSB-first, toggle CLK записью в PINx.

### Хранилище (новый раздел)
- `Eeprom`: границы проверяются всегда (EEAR 10-битный, addr>1023 → порча).
  Тайминг deleгирован avr-libc. Байтовые операции под AtomicBlock.
  `update()` пишет только при отличии; `written()` — счётчик износа.
  Блочная запись N байт = N×3.4 мс: при активном WDT кормить между порциями.
- `EepromStore<T>`: формат блока сохранён прежним — crc(2)+size(2)+ver(1)+data.
  CRC считается по size_lo, size_hi, ver, data. Существующие данные читаются.
  `T` обязан быть trivially copyable (`static_assert`).
  `tick()` смотрит флаг dirty, CRC считает только `commit()`.
  Запись двухфазная: данные, затем заголовок.

### Питание и аналог (новый раздел)
- `Power::Mode` → маска SMCR хранится готовой; `sleepOnce()` её применяет,
  а не пересчитывает из enum.
- Последовательность сна: сохранить SREG → cli → sleep_enable →
  sleep_bod_disable → sei → sleep_cpu → sleep_disable → восстановить SREG.
- Источник пробуждения не проверяется: все прерывания запрещены → сон до WDT.
- `setClockDivider` и `disable(PeripheralTimer0)` отвергаются, пока
  `FN_TIMER0_DEVICE == FN_OWNER_ARDUINO`. В составе `PeripheralAll` Timer0
  фильтруется молча.
- `adjustOsccal` действует только на внутренний RC; на плате с кварцем пустой.
- `Adc`: частота 50–200 кГц для 10 бит; `readMux()` отбрасывает первую
  конверсию после смены входа; `read10()` атомарен; `read8()` корректен
  только при Bits8. DIDR0 — обязанность модуля, не Power.
- `AnalogComparator`: свой гейт `F_USE_AC`. Работает в PowerDown и будит МК —
  единственный аналоговый источник пробуждения. Режим Mux требует ADEN=0,
  `setNegativeMux()` гасит его сам и запоминает состояние.

### PWM
- Слой **замещает** `analogWrite()` на D3/D5/D6/D9/D10/D11. Смешивать нельзя.
- Один шаблонный движок `pwm::Engine<Traits>`, три traits-структуры.
- Traits обязаны предоставить `tccrBKeep`: у Timer0/2 бит 4 — WGM02/WGM22,
  маска 0xE0 его сохраняла и ломала смену режима.
- Timer0: режимы *Top запрещены (сломают millis), частота фиксирована ядром.
- Таймеры без ICR в *Top: канал A недоступен как выход (TOP = OCRnA).
- Кламп скважности до TOP, не до TOP+1: при TOP=MAX значение 256 не влезает
  в регистр и даёт 0%.
- Направление вывода задаёт вызывающий через `regs::modeOutput`.

## 5. Критерии готовности модуля

Модуль считается готовым, когда:

1. Шапка содержит НАЗНАЧЕНИЕ / API / ОГРАНИЧЕНИЯ / СТОИМОСТЬ / ПРИМЕР / ЗАВИСИМОСТИ.
2. Заявлены все занимаемые ресурсы (`FN_CLAIM_*`).
3. Известен `sizeof` каждого объекта и объём статических данных.
4. Нет таблиц в RAM, нет 64-битной арифметики и float в горячих путях.
5. Все многоисходные операции возвращают `Result`, границы проверены.
6. **Нет бесконечных ожиданий железа; таймауты через `expired()`.**
7. **Подбор делителя не превышает запрошенную частоту.**
8. Проверено на железе или численно (для CRC — контрольные значения).
9. Внесён в этот файл, если меняет контракт или владение ресурсом.

## 6. Реестр решений

| ID | Решение | Причина |
|---|---|---|
| D1 | Crash как общий узел Assert/Reset | иначе дублирование работы с WDT и .noinit |
| D2 | Ассерты через PSTR | десятки байт SRAM на каждый ассерт |
| D3 | Policy Halt/Reset вместо cli;for(;;) | при активном WDT «останов» был тихим ребутом |
| D4 | Регистры без таблиц указателей | 18 байт SRAM + косвенный доступ убивал sbi/cbi |
| D5 | Toggle через PINx | одна запись, атомарно, без RMW |
| D6 | 8-битные read/write без cli | аппаратно атомарны, лишние ~6 тактов |
| D7 | Pin в 1 байт | вдвое дешевле на таблицах сигналов жгута |
| D8 | CRTP-ядро битовых массивов | устранено дублирование Pack/Wide |
| D9 | Единый CRC-движок, Maxim init=0x00 | 11 копий цикла; init=0xFF давал 0x0B вместо 0xA1 |
| D10 | Progmem+PgmUtils слиты | две реализации, ambiguous Print, переполнение буфера |
| D11 | Таблицы в Tables.cpp | предсказуемый расчёт flash |
| D12 | ForMacro 64 уровня, FN_FM_* | зарезервированные имена, объём препроцессинга |
| D13 | Диспетчер Irq + compile-time владение | 25 модулей на 5 векторов |
| D14 | layoutOk() рантаймово | &PORTB не constant expression |
| D15 | .init3 вместо init_priority | порядок конструкторов между TU не гарантирован |

## 9. Порядок работ (заменяет ROADMAP 4+)

Слой готов → следующий. Внутри слоя: аудит → контракты → код → проверка → запись.

- [x] L0 конфиг и диагностика (ConfigCheck, Features, Config, Compiler, Types, Crash, Assert, Reset)
- [x] L1 доступ к железу (Atomic, Registers, Memory)
- [x] L2 битовый слой (BitMask/Scan/Count/Ops/Shift/Reverse/Pack/Set/Flags, Bits, Tables)
- [x] L3 данные (Progmem, Crc, ForMacro)
- [x] L4 прерывания и ресурсы (Resources, pin/Irq)
- [x] L5.1 pin (Board, Pin, PinRef, Port, Pulse; Quadrature/PulseInput — см. G4/G5)
- [x] L5.2 timer (TimerCommon, Tick, Timer0, Timer1, Timer2, Watchdog)
- [x] L5.3 PWM (Pwm, PwmCommon, PwmTimer0/1/2, PwmImpl)
- [x] L6 bus (BusContract, Buffer, Uart+Soft, I2c+Soft, Spi+Soft, Packet*)
- [x] L6.1 store (Eeprom, EepromStore)
- [x] L6.2 peripheral (Power, Adc, AnalogComparator)
- [ ] **L7 logic** — следующий: Debounce, Button, Encoder, Filter, Pid, Task,
      Looper, StateMachine, Ramp, Smooth, Hysteresis, Sequencer, Joystick,
      KalmanFilter, PidAutoTune, Menu
- [ ] L8 string/math (StringN, Any, Mapping, Interpolation, Approximation,
      Statistics, LinearRegression, FixedPoint)
- [ ] L9 display (Hd44780, Lcd1602, Lcd1602I2c, OledDisplay, GraphicsDisplay,
      ScrollingText, CharBar/Matrix/Plot, DisplayMenu)
- [ ] L10 device/motor/input (ShiftRegister, Servo, MCP23017, StepperDriver,
      A4988, DRV8825, TMC2209, Keys, Keypad4x4, Keypad4x4Interrupt)

\* выдано патчами — см. раздел 8.

### Требования к слою logic (фиксируются заранее)

- `Task`/`Looper` **не занимают таймер**: время из `Tick`, сравнения через
  `expired()`. Иначе конфликт с арбитражем ресурсов.
- `Debounce`/`Button`/`Encoder` работают через `irq::PinChange` либо опрос,
  своих ISR не пишут.
- `Encoder` — на базе `QuadDecoder` (после закрытия G4), не вторая реализация.
- `Filter`/`Pid`/`Kalman`: целочисленный путь по умолчанию, float — опция.
  Soft-float ≈ 600 Б flash на операцию.
- `StateMachine`/`Sequencer`: без динамической памяти, таблицы состояний
  в PROGMEM.
- `Menu`: зависит от панели — уточнить до выдачи (см. открытые вопросы).
