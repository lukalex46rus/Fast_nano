# Roadmap: архитектурная переработка Fast_nano

**Проект:** Fast_nano (ATmega328P / Arduino Nano)
**Версия:** 2.0 · **Дата:** 17.11.2026
**Тулчейн:** Arduino IDE 2.3.10, avr-gcc 7.3.0, -std=gnu++11, -Os -flto,
-fno-exceptions -fno-threadsafe-statics. Бюджет: SRAM 2048 / flash 32768 / EEPROM 1024.
**Цель:** явная многомодульная многослойная архитектура (L0–L10) с формализованными
контрактами, инвариантами и правилами зависимостей; комплект docs/ — единственный
источник истины.

**Отличия от типового шаблона:** нет DMA (конкурентность = ISR vs main + SPSC);
один разработчик (самопроверка вместо командного ревью); слои L0–L10 уже заданы;
этап 0 (аудит) выполнен; добавлена горячая ветка P0 (разблокировка сборки).

## Риски и зависимости

| Риск | Митигация |
|---|---|
| Несобираемый базлайн блокирует миграцию | Горячая ветка P0 до этапа 3 |
| Двойственность compile-time claim vs runtime acquire | Единая модель владения (п. 1.4) |
| Контракты «на бумаге», код расходится | Проверки предусловий + линтер инвариантов + backlog расхождений |
| Регресс SRAM/flash/таймингов | Бюджеты RESOURCES.md, avr-size/objdump после каждого этапа |
| Зачаточные слои ломают umbrella | Гейт F_USE_*, ядро через Fast_nano_core.h (п. 1.5) |
| Устаревание доков (один разработчик) | Гейт «код+док в одном коммите», чек-лист самопроверки |
| Дублирование фактов между доками | Карта владения фактами, ссылки вместо копий |
